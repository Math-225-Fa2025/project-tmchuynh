A.3 Visualization: Average Rating Comparison

player_summary_long <- player_summary %>%
  pivot_longer(
    cols = c(fide_avg_rating_standard, lichess_avg_rating),
    names_to = "source", values_to = "rating"
  ) %>%
  mutate(source = recode(source,
    fide_avg_rating_standard = "FIDE (Blitz)",
    lichess_avg_rating = "Lichess (Online)"
  ))

ggplot(player_summary_long, aes(x = rating_group, y = rating, fill = source)) +
  geom_col(position = "dodge", width = 0.7) +
  geom_text(aes(label = round(rating, 0)), position = position_dodge(width = 0.7), vjust = -0.5, size = 3.2) +
  scale_fill_manual(values = c("#2E86AB", "#E67E22")) +
  labs(
    title = "Average Player Ratings: FIDE vs. Lichess",
    subtitle = "Comparison by Rating Group (Simulated Distribution, n ≈ 500–900 each)",
    x = "Rating Group",
    y = "Average Rating",
    fill = "Data Source"
  ) +
  theme_minimal(base_size = 12)

Observation: Lichess rating averages may differ systematically from FIDE values due to differing player pools and rating inflation between online and over-the-board ecosystems. The mid-tier groups typically show closer alignment, while extreme ends (Under-1600 and 2600+) exhibit greater divergence.

A.5 Analytical Commentary

Summary of Findings:

  1. There is a measurable rating offset between online (Lichess) and official (FIDE) distributions, reflecting the structural differences in rating systems.
  2. Win rates are relatively stable across rating groups, with a mild upward trend among higher-rated users, consistent with greater consistency and lower variance.
  3. The number of games played increases modestly with rating, implying experience and activity correlate with performance sustainability.
  4. The performance gap metric provides a proxy for inflation or competitive bias — a useful baseline for future normalization across rating systems.
