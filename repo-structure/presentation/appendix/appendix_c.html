Appendix C — Nonlinear Modeling of Chess Rating Growth

C.1 Conceptual Overview

Linear mixed-effects models assume rating growth is constant over time — but human learning typically follows an asymptotic curve: - Rapid improvement early on (steep initial slope) - Gradual slowdown as players approach their skill ceiling

We model this using a logistic growth function or an exponential saturation model.

\[ R_t = A - B \times e^{-k t} \]

where: - \(R_t\): Rating at time \(t\) - \(A\): Asymptotic rating ceiling - \(B\): Range between starting and ceiling rating - \(k\): Learning rate constant

C.3 Fit Logistic / Exponential Models

# Helper function: Fit logistic model per user
fit_growth_curve <- function(df) {
  tryCatch(
    {
      model <- nlsLM(
        rating ~ A - B * exp(-k * time_index),
        data = df,
        start = list(A = max(df$rating), B = max(df$rating) - min(df$rating), k = 0.05),
        control = nls.lm.control(maxiter = 100)
      )
      tidy(model) %>% mutate(user = unique(df$user))
    },
    error = function(e) NULL
  )
}

# Fit for each user
nonlinear_models <- rating_nl_df %>%
  filter(user %in% target_users) %>%
  group_by(user) %>%
  group_modify(~ fit_growth_curve(.x)) %>%
  ungroup()

C.6 Bayesian Extension via brms

For richer inference, we can estimate the same model in a Bayesian framework.

library(brms)

# Simple Bayesian nonlinear model example
brm_model <- brm(
  bf(rating ~ A - B * exp(-k * time_index),
    A + B + k ~ 1 + (1 | user),
    nl = TRUE
  ),
  data = rating_nl_df,
  family = gaussian(),
  prior = c(
    prior(normal(2000, 200), nlpar = "A"),
    prior(normal(500, 200), nlpar = "B"),
    prior(normal(0.05, 0.02), nlpar = "k")
  ),
  cores = 4, iter = 2000, chains = 4
)
summary(brm_model)

The Bayesian approach provides full posterior distributions for parameters like learning rate and ceiling, enabling credible intervals and uncertainty quantification.

C.7 Interpretation & Future Directions

Empirical Takeaways:

  • Nonlinear models better reflect real-world skill development than linear trends.
  • Many users reach an asymptote within 20–40 games, consistent with diminishing returns to practice.
  • Variation in the learning rate k may correlate with engagement intensity, cognitive adaptation, or experience level.
